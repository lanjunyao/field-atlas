使用帮助
左侧管理数据，右侧完成地图工作。项目与离线包保存在本机 Library/Application Support/FieldAtlas 目录。
  1. 画图：选“点 / 线 / 面”，在地图上点击。线和面双击结束，Esc 取消。
  2. 编辑：切回“选择”，单击对象，拖动顶点；Alt + 单击顶点删除。⌘Z 撤销。
  3. 换图：“图源”页切换底图，可接入自己的 XYZ / TMS 栅格瓦片服务。
  4. 离线：框选区域、选择允许下载的图源并创建包。完成后点“使用”，即仅从本机读取。
  5. 交换：导入 GeoJSON / KML / KMZ / GPX / CSV；独立导出 MBTiles 保存地图。
内置公共 OpenStreetMap 只在线浏览。演练底图用于断网功能验证。首版不含奥维私有文件、CAD、GeoTIFF、WMTS 和三维支持。
