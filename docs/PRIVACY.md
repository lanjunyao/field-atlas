# 隐私与网络

项目文件留在本机；没有遥测、云端生成或账号服务。地图视野通过瓦片坐标向所选图源发送，在线模式会产生网络请求。EOX 和 OpenStreetMap 的在线服务适用其服务条款。用户自定义图源经本地代理读取。

离线包模式只从本地 SQLite/MBTiles 读取瓦片，不回退在线图源。软件更新和 npm 安装是另外的联网过程。

图源 URL、名称与查询参数写入项目和备份。不要在 URL 中共享私人 token。浏览器草稿保存在当前浏览器 IndexedDB；清理浏览器数据会移除它们。本机快照位于 `backups/`，不构成异机灾难备份。

默认服务只监听回环地址。本软件面向个人本地使用，不要直接作为公网多用户服务部署；当前没有用户认证或租户隔离。

本仓库的样例、测试和截图标注均为合成演示数据。用户原始业务文件、真实地图包、运行日志及本地分析证据不发布。
