# 运行、备份与恢复

源码启动：`npm run build` 后 `npm start`，浏览器访问 `http://127.0.0.1:9847`。`Ctrl+C` 停止服务。

Mac 源码打包：`npm run package:mac` 生成上一级 `野图.app`。包使用构建机器的 Node 及架构，未签名、公证。双击后启动独立后台监管进程。重复启动不创建第二个监管实例；子服务崩溃按退避间隔重启，短时间连续失败超过5次停止并记录日志。窗口关闭不会自动停止服务。执行源码目录的 `停止野图.command` 可以正常停止监管进程和服务。重新双击应用可再次启动。整机重启后需重新打开应用，未安装登录自启项。

默认 Mac 数据目录：`~/Library/Application Support/FieldAtlas/`。主要文件是 `project.json`、`packages.json`、`packages/*.mbtiles`、`backups/`、`recovery/` 与日志。不要把此目录提交到公开仓库。

项目按临时文件、fsync 和原子替换保存。内容变化产生历史快照；只移动视图不重复保存内容历史。每类历史最多100份或约256MB，至少保留5份，因此大文件最低保留容量可能超过256MB。历史备份有 SHA256 校验；主文件损坏时尝试最近有效副本，原损坏文件留存于 `recovery/`。全部副本无效时停止加载，不用空项目覆盖。

浏览器保存已提交编辑的待保存草稿。断连后重试；刷新发现不同草稿时由用户选择恢复。多个窗口修改同一内容时会提示版本冲突：先导出草稿，再重新载入核对。未提交字段或写入尚未完成的极短时段不保证恢复。

文件页可以导出当前项目或历史项目，再通过“恢复项目备份”恢复。地图包需另外导出 MBTiles。完整迁移前建议停止服务并复制整个数据目录；定期另存到其他设备。

未验证范围：真实整机断电、所有睡眠唤醒组合、所有图源和大规模长时间负载。测试覆盖了强杀子进程、主文件损坏、保存断连、连续刷新、版本冲突和有限区域离线。
